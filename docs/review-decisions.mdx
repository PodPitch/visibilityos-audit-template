---
title: Resolve AI Answer Scoring Disagreements
description: How to keep an evidence trail and resolve disputed brand mention and link labels in a VisibilityOS audit.
---

A reviewer can read an answer as a correct brand mention while a second reviewer sees a different company with the same name. Keep both readings, the cited evidence and the reason for the final label.

## Review the same captured answer

Give both reviewers the identical answer text and source list. Have each person record a `mentioned` rating and a `linked` rating, with one sentence that points to the evidence. If a citation has redirected, keep the displayed citation and the final address.

## Decide what evidence would resolve the difference

- If identity is disputed, compare the answer's product category and cited site with the approved brand names and official destinations.
- If link presence is disputed, inspect the answer and source panel. Confirm whether the link resolves to an approved official destination.
- If a source is unavailable or ambiguous, record the problem and leave the row out of the matched comparison until the evidence can be verified.

## Save the decision

Keep the original answer, both initial labels, the final labels, the evidence and the reason for any correction. If a reviewer changes a label after seeing new evidence, preserve the earlier decision as part of that record. Add a dated note when you change the scoring rule for later audits.

For examples of mention and link labels, see the [VisibilityOS Citation Labeling Reference](https://visibilityos-citation-labels.lovable.app/). For a same-name collision, use the [Brand Identity Audit guide](https://visibilityos-brand-identity-audit.framer.website/).
