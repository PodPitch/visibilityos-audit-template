Count each source consistently

  1. Save the evidence. Record the exact prompt, model, date, answer text, and cited URLs.
  2. Count each destination once per answer. Two links to the same page count once. Two different pages on one site count separately.
  3. Classify the page you actually land on. A publication’s review belongs under Editorial. A product’s profile on a review marketplace belongs under Directories.
  4. Compare like with like. Keep the prompt, model, and counting rules consistent. Record the number of answers and total citations alongside each percentage.
