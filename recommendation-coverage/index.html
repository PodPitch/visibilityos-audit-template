When AI rank improves and coverage falls

A brand can move up the list in the answers that name it while disappearing from more answers overall. Track recommendation position and coverage together.

Fictional example

Run the same eight questions in each round.

Read both results

Before, the brand appeared in positions 1, 3, 4 and 5. After, it appeared once, in first place. Average position moved from 3.25 to 1.00, while three fewer answers named the brand.

The first-place result is worth inspecting. So are the three answers that dropped the brand.

Measure the same questions twice

  1. Ask for numbered recommendations. Keep the question, engine, search settings and market consistent.
  2. Record the brand’s first position when it appears. Count brand appearances and top-three appearances against all completed eligible answers in the matched sample.
  3. Report average position among appearances alongside both coverage measures. Track missing and failed answers separately.
