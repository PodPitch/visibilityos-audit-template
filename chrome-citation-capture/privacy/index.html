VisibilityOS Citation Capture

Extension privacy

VisibilityOS Citation Capture is a PodPitch extension that prepares a local text file containing a source URL, the source passage you choose, and an optional AI claim you enter.

Information the extension uses

When you open the extension and choose Capture from this tab, it uses Chrome’s temporary access to the current tab to read that page’s URL and your selected text. You can also paste the information into the form. The extension reads no browsing history and runs no background page monitoring.

Where the information goes

The extension processes that information in the popup on your device. It sends no information to PodPitch or any other service, collects no analytics, uses no advertising, and has no account or cloud storage. Closing the popup clears its fields. When you choose to save a record, Chrome saves a text file. You can remove that file using your device’s file controls.

Chrome Web Store Limited Use

VisibilityOS Citation Capture uses the selected text and URL solely to prepare the evidence file you request. The extension’s use of this information adheres to the Chrome Web Store Limited Use requirements.
