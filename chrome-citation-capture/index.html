Citation Capture

Save the exact passage you want to keep and the URL where you found it. Citation Capture is a browser extension for collecting source evidence during an AI citation audit.

Capture a passage

  1. On the cited source page, select the passage you want to keep.
  2. Open Citation Capture in the toolbar and choose Capture from this tab.
  3. Review the URL and passage, add the AI claim if helpful, then choose Save evidence record.

If you cannot capture a passage from a web page or PDF, paste its web URL and the passage into the form yourself.

The file stays on your device. A captured passage is evidence for review. Read it in context before deciding whether it supports the AI claim.
