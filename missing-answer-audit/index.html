How the range works

Among the complete pairs, subtract losses from gains and divide by the number of complete pairs. For the full range, give every unknown answer the value that produces the biggest loss, then repeat for the biggest gain. Divide both totals by the number of planned pairs. The change is in percentage points.

The range shows the possible outcomes for this set of questions. If it includes both gains and losses, first check whether you can recover the missing answers. If you run the audit again, collect a new matched sample and record its dates.
