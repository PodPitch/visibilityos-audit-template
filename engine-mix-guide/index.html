Report a like-for-like comparison

  1. Pair the same questions across dates and keep the engine, model, market, and search settings consistent.
  2. For each engine, divide the number of answers that mention the brand by the number of usable answers. Keep failed and missing answers out of that denominator.
  3. Choose weights before reviewing the results and apply them to both rounds. In this example, giving each engine half the weight yields 50% in both rounds.
  4. Report the per-engine counts, pooled rate, fixed-weight rate, and missing coverage together. Show any engine available in only one round separately.
