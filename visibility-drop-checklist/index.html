AI Search Drop Checklist

When a familiar AI answer stops mentioning your brand, save the evidence and find out exactly what changed before you report a drop.

What changed?

  • The mention disappeared

    Find the brand in the answer body and any recommendations. Record whether it was present in the earlier answer, then repeat the exact prompt in a fresh session using the same model and browsing settings.

  • The official link disappeared

    Compare the cited URLs. If the brand remains in the answer while its website disappears from the sources, record a link loss alongside continued brand presence.

  • The source changed

    Open the new citation. Check whether the page supports the specific claim in the answer. Record the new URL and the sentence that supports or contradicts it.

  • Several answers changed

    Group the affected prompts by buyer intent. Compare the number of matched prompts that gained, lost, or kept a mention. Include the size of the tested prompt set in your report.

Worked example

A comparison answer still names a software product but replaces its pricing page with a directory profile. Record the brand as present and the official link as lost. Check whether the directory actually supports the pricing claim before reporting an evidence problem.

When to report a pattern

In the VisibilityOS AI answer study, brand presence changed in 82 of 817 matched comparisons. Whether the answer linked to the brand changed in 79. Those counts describe the study’s sample and show why saving comparable repeats matters.

If you see the same loss recur, report which prompts changed, over which dates, and how often it appeared. Use the AI search audit plan builder to set up matched checks.
